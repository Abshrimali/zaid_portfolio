# Muhammad Zaid Zaii Portfolio

Modern MERN portfolio with GSAP animations, built to showcase real projects and full-stack experience.

## Setup

1. Open terminal in `ZaidPortfolio`
2. Run `npm install`
3. Run `npm run install-all`
4. Run `npm run dev`

## Run

- Frontend: http://localhost:5173
- Backend API: http://localhost:4000/api

## Notes

- Add `resume.pdf` in `client/public` and update the download link if needed.
- Set SMTP environment variables in `server/.env` if you want contact form emails to deliver.
